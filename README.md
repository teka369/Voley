# VolleyManager

App para organizar encuentros de voleibol entre amigos: reservas, compañeros, documentos, cupos, gastos y plantillas. Los datos viven en el navegador (no hace falta cuenta).

## Qué puedes hacer

- Crear, editar, duplicar, cancelar y finalizar encuentros
- Llevar el directorio de compañeros y reutilizarlos en cada reserva
- Controlar documentos, asistencia, cupos y el dinero del partido
- Guardar plantillas y revisar el historial
- Exportar e importar los datos

## Cómo correrlo

```bash
npm install
npm run dev
```

Abre la app en el puerto que indique la terminal.
